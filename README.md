# 🌤 Weather App

A modern weather application built with React and OpenWeather API.

## 📖 About

Weather App allows users to search for current weather information in cities around the world.

The project was built to practice React fundamentals, API integration, state management, localStorage, and responsive design.

## ✨ Features

- Search weather by city
- Current temperature
- Weather condition icons
- Feels like temperature
- Humidity
- Wind speed
- Atmospheric pressure
- Sunrise and sunset times
- Search history
- Favorites system
- Loading spinner
- Error handling
- Last updated time
- Clear all data
- LocalStorage persistence
- Mobile responsive design
- Empty state screen

## 🛠 Technologies

- React
- JavaScript (ES6+)
- CSS3
- Vite
- OpenWeather API
- LocalStorage
